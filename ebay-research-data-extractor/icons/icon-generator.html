🎨 Icon Generator for eBay Extension

This tool creates the PNG icons needed for your Chrome extension from the SVG source.

📥 Download Icons

Right-click each icon and save as:

  • 16px → Save as "icon-16.png"
  • 48px → Save as "icon-48.png"
  • 128px → Save as "icon-128.png"
💡 Quick Setup:
1. Save the three PNG icons to your extension folder
2. Put them in an "icons" folder
3. Load your extension in Chrome (chrome://extensions/)
4. Test on eBay pages!
