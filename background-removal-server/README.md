# Background Removal Server

This directory contains the Python background removal service.

## Quick Setup

1. **Create virtual environment:**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
```

2. **Install dependencies:**
```bash
pip install -r requirements.txt
```

3. **Run the server:**
```bash
python app.py
```

## Note
The virtual environment (`venv/`) is excluded from version control. 
Each developer needs to create their own virtual environment locally.
